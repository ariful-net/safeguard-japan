地震・津波・大雨。日本で暮らす留学生が、自分の言葉ですぐに動けるようにするための多言語防災 Web アプリです。

日本語EnglishবাংলাTiếng Việt
アプリを開く → ソースコード

無料サーバーのため、しばらく使われていないと最初の表示に 30 秒〜1 分ほどかかります。

Story

44 秒でわかる、避難の流れ

Features

できること

01

災害情報

気象庁の最新の地震情報を、震度と地域を選んだ言語に直して表示。警報の種類ごとに取るべき行動を示します。

/alert-info
02

避難所マップ

現在地から近い避難所を地図で探し、徒歩ルート・所要時間・到着判定まで案内します。

/shelters
03

安否メッセージ

家族や学校に送る安否メッセージを多言語で作成。内容はサーバーに送りません。

/safety-status
04

防災の備え

人数と日数から備蓄量を計算するカリキュレーターと、チェックリスト、災害別の行動。

/prepare
05

天気バー

現在地の天気を常に画面上部に表示。大雨への備えに。

/api/weather
06

オフライン対応

Service Worker で、通信が不安定なときも基本画面を表示できます。

sw.js

Note

ご利用にあたって

  • 学習用のプロジェクトです。避難所データはサンプルで、位置や対応災害は確認されていません。
  • 正式な警報・注意報は気象庁、避難所はお住まいの自治体の情報を必ず確認してください。
  • 徒歩ルートは FOSSGIS の公開 OSRM サーバー、天気は Open-Meteo を利用しています。
